# SpecPair design

AI-assisted original local prototype; no deployment, publication, hosting, users, rewards or live wallet business-flow claims. Synthetic inputs contain no PII. Constructor has zero arguments. Each unique record ID permanently binds owner, chain, contract, source URLs/byte hashes and policy. OPEN→DERIVED→CONFIRMED, owner can REVOKE terminally from any stage; expectedRevision and exact certificate ID required for confirm. Permissionless one-time derive; source refetched/hash/schema/full result recomputed by leader and every validator during open/derive/confirm. No LLM. Offline revoke is allowed. Each record has at most four history entries. Sources use canonical HTTPS raw.githubusercontent.com owner/repo/40-lowercase-hex/path; every segment rejects dot/empty and no query/fragment/encoding. UTF8 strict JSON rejects duplicates/nonfinite/unknown fields; exact SHA and response200 required, <=16384 bytes each. Bounds are checked after transport, not network bandwidth/redirect controls. No source publisher identity proof.

Frontend: original domain-specific local preview and manual explanation plus MetaMask61999 open→derive→ownerconfirm/revoke, actual decoded dict reads, fullTransaction finalized observation and mandatory independently unformatted raw exact hash/from/to/value0/NORMAL/majority/uniqueleaderSUCCESS proof. Check every provided SDK identity/finality/execution field; missing Studio fields never synthesized. Before broadcast persist public original sender/target/record/method/hash-null context; only explicit4001 rejection clears hashless attempt. Unknown status survives same-tab reload and blocks replay; exact wallet activity hash can attach for observation only. Busy freezes all controls; captured address/record epoch rejects stale reads and callbacks. No keys or private reveal data. Public URLs/deployment/hosting/live remain null; browser visual QA not performed.

## Reconciliation domain and canonical objective
Each source is exactly {version:1,records:[{id,category,unit,value,tick}]} with0..8 unique ASCII IDs matching [A-Za-z][A-Za-z0-9_]{0,23}; category/unit share that grammar; integer value ±1000000 and tick0..1000000, bool rejected. Policy is exactly value_tolerance0..2000000, tick_tolerance0..1000000, value_weight1..1000, tick_weight0..1000. Pair admissible iff category/unit equal and absolute differences fall within tolerances. Pair cost=value_weight*abs(value difference)+tick_weight*abs(tick difference).

ASCII-sort both lists. Suffix bitmask DP over left index and used-right mask explores unmatched and every unused admissible right. Minimize (-matched_count,total_cost,assignment_vector), where vector uses right ASCII index and unmatched sentinel len(right). Max8*256 states; integers remain below safe JS bounds. Certificate returns every left assignment, pair deltas/cost, full admissibility/cost grid, unmatched IDs and objective. Both empty is EMPTY; any other zero-cardinality result is NO_MATCH; otherwise MATCHED. This is synthetic record reconciliation, not identity/delivery or a claim records describe the same real object.

API: open_pair(record_id,left_url,left_sha256,right_url,right_sha256,policy_json); derive_pair(record_id,expected_revision); confirm_pair(record_id,expected_revision,certificate_id); revoke_pair(record_id,expected_revision,reason); get_pair(record_id); get_configuration(). All views return decoded dictionaries. Open creator is record owner. IDs never reused.

UI: independent side-by-side JSON editors/export of exactbytes, admissible pair cost grid, optimal matched/unmatched columns and objective, manual pair selection to explain conflict/cost (local only), chain record overlay with identical deterministic result check. Global-cardinality anti-greedy, mincost, equal-cost canonical tie, empty/no-match and boundary examples are explicitly tested.
